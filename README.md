# MeshkitKeen

Управление mesh-сетью Keenetic с одного терминала.

**MeshkitKeen** — это форк [KeenKit](https://github.com/spatiumstas/KeenKit) (v2.9.5),
добавляющий неинтерактивный режим и управление mesh-узлами (ретрансляторами /
экстендерами) с головного роутера (контроллера).

Скрипт запускается на **контроллере** mesh-сети и одним экраном показывает состояние
всех устройств (контроллер + подключённые mesh-узлы): модель, версию прошивки и
наличие обновления, занятую память (ОЗУ + накопитель OPKG) и нагрузку CPU.

## Возможности

- **`status`** — сводка по контроллеру и всем mesh-узлам (модель, прошивка, обновление,
  ОЗУ, накопитель, CPU, uptime, backhaul).
- **`reboot <self|IP|all>`** — перезагрузка контроллера, одного узла или всех устройств.
- **`wifi <self|IP|all> on|off [2.4|5|6|all]`** — включение/выключение Wi-Fi по диапазонам.
- **`update <self|IP>`** — обновление прошивки по OTA (свой домен, каталог `/osvault`).
- **`add-node <IP>`** — подготовка нового mesh-узла (Entware + ключи).
- **`setup`** — генерация и раздача SSH-ключей для доступа к узлам.
- **`backup-entware` / `backup-block`** — резервные копии Entware и разделов прошивки.

### Поддержка Wi-Fi 7 (6 ГГц)

Скрипт универсален по числу радиомодулей: диапазоны определяются **динамически** из
`show/interface`, поэтому корректно работает и на двухдиапазонных (Wi-Fi 6: 2.4 + 5 ГГц),
и на трёхдиапазонных (Wi-Fi 6E/7: + 6 ГГц, `WifiMaster2`) устройствах. Хардкода количества
радио нет.

## Безопасность

- В репозитории **нет никаких паролей, ключей, лицензий, MAC- или IP-адресов**.
- Доступ к узлам — **только по SSH-ключу** (dropbear :222, Entware), пароли не хранятся.
- Все локальные настройки (домен, пользователь, порт) — в `/opt/etc/MeshkitKeen.conf`,
  который внесён в `.gitignore`.
- Секреты размещаются только на устройстве; в git попадают только плейсхолдеры.

## Установка

Требования: контроллер с [Entware](https://entware.net/) и root-доступом по SSH (`:222`).

```sh
curl -fLsS https://raw.githubusercontent.com/Chistovik92/MeshkitKeen/main/install.sh | sh
```

Затем настройте ключи доступа к узлам:

```sh
meshkitkeen setup
```

Подробности — в [docs/SETUP.md](docs/SETUP.md).

## Использование

```sh
meshkitkeen status                  # сводка по сети
meshkitkeen reboot 192.168.2.51     # перезагрузить узел
meshkitkeen wifi all off 5          # выключить 5 ГГц на всех устройствах
meshkitkeen update self             # обновить прошивку контроллера
meshkitkeen --help                  # все команды
```

Без аргументов запускается интерактивное меню.

> ⚠️ Команды `reboot`, `wifi`, `update` изменяют состояние сети — применяйте их осознанно.
